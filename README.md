# Парсер книг с books.toscrape.com

**Автоматический сбор каталога интернет-магазина в Excel.** Парсер сам проходит
по всем страницам каталога и за ~1 минуту собирает данные о 1000 товарах:
название, цену, рейтинг, наличие и ссылку на карточку. На выходе — готовая
таблица `books.xlsx`: аккуратные заголовки, фильтры, цены числами (их можно
сортировать и считать). Парсер бережно относится к сайту (паузы между запросами)
и устойчив к сбоям сети (повторные попытки загрузки).

Стек: Python, requests, BeautifulSoup, openpyxl.

## Что делает

Проходит по всем страницам каталога (их 50, по 20 книг на каждой — всего 1000 книг)
и по каждой книге собирает:

| Колонка   | Пример                                                        |
|-----------|---------------------------------------------------------------|
| Название  | A Light in the Attic                                          |
| Цена (£)  | 51.77                                                         |
| Рейтинг   | 3 (число от 1 до 5)                                           |
| Наличие   | В наличии / Нет в наличии                                     |
| Ссылка    | https://books.toscrape.com/catalogue/a-light-in-the-attic_1000/index.html |

Результат сохраняется в файл `books.xlsx`: заголовки выделены, ширина колонок
подобрана автоматически, первая строка закреплена, включён фильтр.

Особенности:

- переход по страницам — автоматически по кнопке «next», пока она есть;
- пауза 0.5–1 секунды между запросами, чтобы не нагружать сайт;
- если страница не загрузилась — до 3 попыток; если так и не вышло, страница
  пропускается, а после двух неудачных страниц подряд парсер останавливается
  и сохраняет то, что успел собрать;
- в консоль выводится, какая страница парсится и сколько книг уже собрано.

## Быстрый старт на Windows

Нужен Python 3.9 или новее ([python.org](https://www.python.org/downloads/)).
Команды выполняются в PowerShell в папке проекта. На Windows используем `py` —
это стандартный запускатель Python, он работает, даже если команда `python`
открывает Microsoft Store.

1. Создать виртуальное окружение (один раз):

   ```bash
   py -m venv .venv
   ```

2. Установить зависимости в него (один раз):

   ```bash
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

3. Запустить парсер:

   ```bash
   .venv\Scripts\python parser.py
   ```

Активировать окружение не обязательно: команды выше сразу вызывают Python из `.venv`.
Готовый файл `books.xlsx` появится в папке проекта.

## Установка (macOS / Linux и общий способ)

Нужен Python 3.9 или новее.

1. Откройте терминал в папке проекта.
2. (Рекомендуется) создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

   Windows (PowerShell):

   ```bash
   .venv\Scripts\Activate.ps1
   ```

   macOS / Linux:

   ```bash
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

> На Windows, если команда `python` открывает Microsoft Store, используйте `py` вместо `python`.

## Запуск

```bash
python parser.py
```

Пример вывода:

```
Старт парсинга books.toscrape.com

Парсинг страницы 1: https://books.toscrape.com/catalogue/page-1.html
  + найдено книг на странице: 20, всего собрано: 20
Парсинг страницы 2: https://books.toscrape.com/catalogue/page-2.html
  + найдено книг на странице: 20, всего собрано: 40
...
Готово! Всего собрано книг: 1000
Результат сохранён в файл books.xlsx
```

Полный обход занимает около минуты. Файл `books.xlsx` появится в той же папке.

## Настройки

В начале `parser.py` есть константы, которые можно менять:

- `DELAY_RANGE` — диапазон паузы между запросами (сек);
- `MAX_RETRIES` — сколько раз повторять загрузку страницы;
- `TIMEOUT` — сколько ждать ответа сервера;
- `OUTPUT_FILE` — имя итогового файла.

## Используемые библиотеки

- `requests` — загрузка страниц;
- `beautifulsoup4` — разбор HTML;
- `openpyxl` — создание Excel-файла.
